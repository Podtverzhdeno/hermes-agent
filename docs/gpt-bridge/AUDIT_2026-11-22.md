## Primary risks prioritized
1. False success from assistant message or heartbeat; must require exact-revision independent verification.
2. False failure from missing output/Chrome MV3 worker suspension/CDP detach; status UNKNOWN or suspected only.
3. Duplicate external mutation after timeout; reserve in privileged ledger, reconcile rather than blind retry.
4. Cross-tab or cross-action signal collision in tens of agents; stable target_id/action_id/channel_id plus producer_id/fence.
5. Stale agent commits after reassignment; tool gateway fencing before side effect.
6. Private transcript, session keys or CDP URLs in logs; structured allowlisted metadata only.
7. SDD conflicts across many agents; isolated branches, read-before-write SHA, PR review, explicit ownership.
8. SQLite WAL capacity/corruption; backup API, disk budget, measured capacity, documented limits.

## Review changes and regressions
- Found design error during review: one browser reconnect could have cleared another tab's detach; fixed with target-specific state and regression test.
- Found design error: reconciling effect A could falsely clear unresolved effect B; fixed with action-specific state and test.
- Found multi-agent source-sequence collision risk: differentiate producer_id from logical agent_id.
- Rejected auto-retry on silence. A browser's stopped UI is not a provider's confirmed non-execution.
- A hash chain is for accidental corruption only, not tamper evidence against an attacker with write access.
- Do not claim the observer is live, has source authentication, implements browser integration, or has passed whole-repo CI: none established.
